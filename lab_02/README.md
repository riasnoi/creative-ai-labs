## Проверка без изменения результатов

Нужен Python 3.10 или новее; сторонние пакеты не требуются. Из этой папки:

```bash
python tools/verify_submission.py
```

Проверка сверяет SHA-256, исходный паспорт ЛР01, комплект архива, решения,
кандидат выпуска, категории и оценки рисков. Затем во временной папке повторяет
создание варианта, аудит исходного и отобранного манифеста, проверку реестра
и генерацию исходной карточки модели. Сохранённые артефакты не перезаписываются.

Для самостоятельного повторения учебных команд используйте новую папку:

```bash
python src/lab02_make_variant.py --variant 13 --out /tmp/lr02-repeat/v13
python src/lab02_audit.py --manifest /tmp/lr02-repeat/v13/manifest.csv --policy /tmp/lr02-repeat/v13/policy.json --out /tmp/lr02-repeat/v13
python src/lab02_model_card.py --passport docs/input/lab01_passport.json --out /tmp/lr02-repeat/model_card.md --owner "Рясной Владимир Олегович — составитель карточки и ответственный за учебный эксперимент"
python src/lab02_risks.py --csv artifacts/risk_register.csv --out /tmp/lr02-repeat/risk_ranking.md
```

## Происхождение и ограничения

`src/` содержит пять неизменённых скриптов преподавателя; хеши — в
[provenance.json](artifacts/provenance.json). `docs/` содержит методичку,

`docs/generated/` — исходные автоматические заготовки для прослеживаемости;
завершённые документы находятся в `artifacts/`. Заготовки не выдаются за
заполненный результат. Табличные даты, правообладатели и адреса `example.org`
вымышлены; WAV/TXT/PNG из манифеста отсутствуют. Их SHA-256 вычислены от строк,
а не медиабайтов. Реальные персональные данные в учебные записи не добавлялись.

У генератора ЛР01 нет обучения и весов. Лицензия его кода не установлена;
карточка ограничивает внешнее применение до подтверждения прав. В реестре
6 рисков и 6 категорий, включая обязательные Data Privacy и
Harmful Bias or Homogenization; проверка дала `RESULT: PASS`.

учебный комплект сопровождает составитель. Репозиторий не устанавливает
