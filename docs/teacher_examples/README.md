# Примеры преподавателя

`demo_journal/` содержит исходный демонстрационный вариант 1 и журналы
преподавателя от 18 сентября 2026 года (Windows, Python 3.13.7).

результатами варианта 13. Собственная работа находится в `ЛР01/artifacts/`,
а журнал — в `ЛР01/experiment_journal_v13.md` относительно корня репозитория.
