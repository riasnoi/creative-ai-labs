## Как проверить расчёты

1. Открыть README и отчёт; сравнить условия опыта и заключение.
2. Запустить `python tools/verify_submission.py` в среде Python 3.10+.
3. Убедиться, что проверка завершилась с кодом 0 и сообщением
   «Проверка пройдена». `--quick` пропускает только повтор серии n=50.
4. При необходимости самостоятельно запустить учебный скрипт с параметрами
   из README. Сохранить повтор в `.runs/`, чтобы не заменить исторический опыт.

Проверка не требует Word, `python-docx`, Engee, Интернета или сторонних данных.
Полные хеши находятся в JSON; в Word и Markdown для компактности показано начало.
`MANIFEST.sha256` проверяет целостность передаваемого комплекта, а `sha256_pixels`
подтверждает воспроизводимость научного результата. Это разные проверки.

## Границы вывода

Учебный критерий `abs(Δ) > 2 * s_base` задан до основного опыта и не заменяет
формальный тест. Во всех четырёх метриках эффект по этому правилу не обнаружен.
Вывод относится к генератору и указанным параметрам; эстетика обложки не измерялась.

В дополнительной серии SE разности оценена как
`sqrt(s_base²/n + s_factor²/n)`. Это приближение без учёта зависимости серий:
база и фактор используют одинаковые seed. Значение 2.61 для энтропии не является
готовым p-value или результатом парного теста. Для формальной проверки следует
сохранять метрики каждой пары seed и учитывать парный дизайн.
