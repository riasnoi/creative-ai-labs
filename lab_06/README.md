## Повтор в Colab

Загрузите [блокнот](src/lab06.ipynb) в **новый** Colab-сеанс Python 3 / T4 и выполните четыре ячейки сверху вниз. Первые две записывают библиотеки, третья фиксирует план до загрузки моделей и выполняет опыт, четвёртая скачивает архив. Дополнительные пакеты в использованном образе Colab уже присутствовали. Повтор сохраняйте отдельно от исходных результатов.

[Онлайн-блокнот](https://colab.research.google.com/drive/12i4mFkFRDSi9LqWo3nNZAwisZVEopA4d) — доступ управляется владельцем; локальная копия с outputs доступна в репозитории.

Фактическая среда: Python 3.13.15, torch 2.11.0+cu130, CUDA 13.0, diffusers 0.40.0, transformers 5.18.0, Pillow 11.3.0, numpy 2.1.3, scipy 1.16.3. [Зависимости](requirements-colab.txt) фиксируют Python-пакеты; CUDA-сборка torch определяется образом Colab. Полные `nvidia-smi` и `pip list` включены в паспорт среды. Время и побитовые результаты на иной среде не гарантируются.

Для запуска из каталога `lab_06` в совместимой CUDA-среде:

```bash
PYTHONPATH=src/original python src/run_lab06.py
```

Программа требует отсутствия `artifacts/` в рабочем каталоге, чтобы не заменить первичные данные. Для нового опыта скопируйте `src/` и зависимости в пустую папку и выполните команду оттуда. В опубликованном комплекте `artifacts/` уже существует, поэтому повтор намеренно остановится до генерации.

## Проверка без GPU

Из папки `lab_06`:

```bash
python -m pip install -r requirements-verify.txt
python -B tools/verify_submission.py
```

Независимо пересчитываются Sobel и контраст десяти PNG, агрегаты четырёх метрик и PSNR ошибки guidance; проверяются хеши, сравнительный лист, хронология плана, код блокнота и отсутствие ошибок в outputs, исходный архив, Word/PDF и манифест. CLIP заново локально не вычисляется; проверяется агрегирование сохранённых исходных значений. Полная генерация повторно на новой машине не запускалась.
