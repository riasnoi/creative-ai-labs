## Структура и воспроизводимость

`tools/verify_submission.py`: проверяет библиотечные ячейки и программу блокнота, execution_count/outputs без исключений, совпадение байтов первичных файлов с исходным ZIP, DOCX/PDF и SHA-256 всего комплекта. Проверка без GPU выполнена из чистой копии; перезапуск модели для такой проверки не требуется.

Повтор опыта выполняется в новом каталоге. Защита `assert not OUT.exists()` сохраняет первичные данные опубликованного комплекта. README содержит относительные рабочие ссылки и команды из папки lab_06. Старые лабораторные не изменены; корневые правки ограничены навигацией, атрибутами и обновлением соответствующих хешей.

## Публикуемый снимок

Полнота манифеста и SHA-256 проверены по байтам индекса Git; весь будущий снимок просмотрен на запрещённые файлы, служебные материалы и типовые секреты. Локальная копия и индекс проходят автоматический аудит. Тексты исходных библиотек, блокнот и исходный журнал сохраняют первоначальные байты. Рендеры QA, веса моделей, окружения и кеши в снимок не входят.

После публикации проверка повторяется в свежей копии с GitHub; итог внешней проверки сообщается при передаче работы.

Чистая копия проверена локальным Python 3.12.14, numpy 2.3.5, Pillow 12.3.0 и pypdf 6.10.0. Точные версии проверяющего интерпретатора записаны в independent_verification.json. Проверка не требует scipy. Пробелы на концах строк исходных карточек моделей и лицензий сохранены как в источниках; собственные тексты и код проходят проверку пробелов Git.
