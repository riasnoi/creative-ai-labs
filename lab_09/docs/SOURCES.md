# Источники и происхождение

Дата обращения к сетевым источникам: 01.11.2026.

1. [Методические указания ЛР09](ЛР09_Промпт-инжиниринг_МУ.pdf), предоставлены вместе с пятью учебными Python-файлами. Синтетические описания разрешены методичкой к свободному использованию. SHA-256 исходников: SOURCE_PROVENANCE.json. Файлы в src/original сохранены без изменений, включая CRLF.
2. [SD Turbo, закреплённая ревизия](https://huggingface.co/stabilityai/sd-turbo/tree/b261bac6fd2cf515557d5d0707481eafa0485ec2). [Stability AI Community License в этой ревизии](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/LICENSE.md). Учебное некоммерческое использование; веса не распространяются. Powered by Stability AI.
3. [CLIP ViT-L/14](https://huggingface.co/openai/clip-vit-large-patch14). [MIT License официального CLIP](https://github.com/openai/CLIP/blob/main/LICENSE). Веса и код CLIP в комплект не включены.
4. [Условия ChatGPT](https://openai.com/policies/row-terms-of-use/). В сервис переданы только учебные синтетические описания; ответы обозначены как результаты языковой модели. Точная модель не раскрывается интерфейсом.

В процессе работы условия SD Turbo просмотрены при подготовке опыта; условия CLIP и ChatGPT дополнительно сверены при проверке комплекта. Новые соглашения и платные тарифы не оформлялись. Студенческие реквизиты находятся в титуле; в экспериментальные запросы они не включались.
