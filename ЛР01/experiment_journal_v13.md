# Журнал эксперимента ЛР 1 вариант 13

## Предварительная регистрация

- Дата и время фиксации: 2026-09-24 16:40:22 MSK (13:40:22 UTC).
- Вариант: 13.
- Контекст: мраморный узор для обложки.
- Изменяемый фактор: размер изображения x1,5, с 96 x 96 до 144 x 144 пикселей.
- Базовый seed: 101.
- Серия: n = 5, seed 101, 102, 103, 104, 105.
- Заранее заданный критерий: эффект метрики считается существенным, если абсолютное значение разности средних превышает удвоенное выборочное стандартное отклонение базовой серии, то есть |delta| > 2 * s_base.

### Гипотеза до запуска

Увеличение размера изображения при неизменных параметрах решётки, числа октав, затухания, квантования и интерполяции увеличит число случайных узлов, попавших в кадр, но не изменит заданный масштаб деталей и закон формирования яркости. Поэтому ожидается, что средняя яркость, контраст, граничная энергия и энтропия не изменятся сильнее естественного разброса между seed: для каждой из четырёх метрик ожидается |delta| / s_base <= 2. Для применения как фона обложки отдельно оцениваются баланс детальности по энтропии и граничной энергии и контролируемость контраста.

### Условие пересмотра вывода

Гипотеза будет опровергнута для конкретной метрики, если после серии из пяти seed выполнится |delta| > 2 * s_base. Вывод будет ограничен данной реализацией генератора, указанными параметрами и n = 5.

### Дополнительная проверка при n = 50

После завершения обязательного эксперимента выполнена дополнительная серия:

```text
python src/lab01_experiment.py --variant 13 --seed 101 --n 50 --out artifacts/v13_n50
```

По заранее заданному учебному критерию `|delta| > 2 * s_base` ни одна метрика также не признана существенно изменившейся. Отношения `|delta|/s_base`: средняя яркость 0.10, контраст 0.25, граничная энергия 0.002, энтропия 0.45.

Для дополнительной оценки рассчитана стандартная ошибка разности средних `SE_delta = sqrt(s_base^2/n + s_factor^2/n)`. Отношения `|delta|/SE_delta`: 0.52, 1.43, 0.01 и 2.61 соответственно. Это не изменяет заранее заданный вывод лабораторной работы, но показывает ограниченность правила `2s_base`: при увеличении n оценка среднего уточняется, тогда как порог `2s_base` не учитывает размер выборки. Для энтропии результат серии n = 50 служит основанием предложить отдельную проверку формальным статистическим методом.
